yt-dlp下载各网站视频

Author: Henry Li   Date: 2026-10-19   Category: 技术速记    本文阅读量: 次

一、下载视频主流工具

版权与合理使用：下载的视频严禁用于任何商业用途或未经授权的二次传播。在未获得版权方授权的情况下，对下载的视频进行剪辑并公开传播，可能构成侵权

1. 在线网站（无需安装）

  • Cobalt：一个开源、无广告的在线工具，支持B站、YouTube等20多个平台。你只需粘贴视频链接，即可选择下载视频或仅下载音频，适合在不想安装任何软件时快速使用。

2. 命令行工具（适合进阶用户）

工具名称 核心特点 安装方式
BBDown 功能全面，支持番剧、课程、弹幕、字幕下载，可调用 aria2c 多线程加速。 dotnet tool install --global BBDown
yutto 专注于B站，支持大会员内容，自带弹幕生成（ASS格式）。 pip install yutto
bili23-cli 轻量级，能复用GUI版登录状态，无需重复登录即可获取高画质。 pipx install bili23-cli 或 uv tool install bili23-cli
yt-dlp 通用型下载器，支持超过1700个网站，youtube、B站是其中之一，生态成熟。 pip install -U yt-dlp
bili-dl 专为B站设计，支持自动续期登录状态，音频输出对foobar2000友好。 pipx install bili-dl

大多数工具的使用方式都非常直接，只需在终端输入命令并跟上视频链接即可。

参数 作用
直接使用 -x 自动选择最佳的音频流并保存为原始格式
--audio-format 指定音频格式，如 mp3、flac、m4a、wav 等
--audio-quality 控制音频质量,指定 0（最佳）到 10（最差）之间的 VBR 质量值，或直接指定比特率（如 128K）。默认值为 5

📌 参数说明

参数 作用
-P "~/Downloads" 保存到指定目录
-o "%(title)s.%(ext)s" 保存文件名，可用 %(title)s 、%(ext)s 、%(uploader)s、(upload_date)s等占位符来自动生成文件名
-f "bestvideo[height<=1080][vcodec^=avc1]+bestaudio[ext=m4a]/..." 指定画质，基本格式选择器**best、bestvideo+bestaudio、bestvideo、bestaudio。使用 height 参数来限制最大分辨率，4K视频把1080换成2160。或者直接用指明ID
--merge-output-format mp4 指明下载视频格式,支持
--write-auto-subs 下载 YouTube 自动生成的字幕
--embed-subs 把字幕嵌入视频中，作为可开关的软字幕轨道
--sub-langs "en" 只嵌入英文字幕；多语言用逗号分隔，如”zh-Hans,en”
